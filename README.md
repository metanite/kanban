# A Simple Kanban Web Application
This repository contains a kanban (like Trello or JIRA Board) web application implement using OpenAI Codex, Laravel, SQLite, InertiaJS, and ReactJs.

<img width="1911" height="904" alt="kanban" src="https://github.com/user-attachments/assets/956352fa-00bb-4eb9-b98d-639ef6c59951" />

## Features:
- Authentication
- Dashboard
- Create Tickets
- Move Tickets to other columns
